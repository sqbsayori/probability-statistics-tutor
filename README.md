# 概率论与数理统计 交互式学习导师

> 基于《概率论与数理统计》教材全12章，面向大学理工科/经管类专业学生的 AI 交互式学习系统。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 功能特性

- **全教材覆盖**：12章完整课程体系，从随机事件到回归分析（~240个知识点）
- **微步教学模型**：每个知识点拆分为2-6个微步骤，每步 ≤ 100 字
- **STEP-Prove 双轨解题法**：计算题用 STEP 法（审题→方法→执行→验证），证明题用 Prove 法
- **掌握度追踪**：连续答对达到阈值才算掌握，自适应调整难度和出题频率
- **学生注册系统**：支持学校+学号注册或匿名学习，进度跨会话持久化
- **学习历史记录**：记录每次学习的进度、正确率、薄弱点
- **智能学习建议**：根据进度给出下一步学习建议，后面章节已掌握时不建议学习前面章节
- **学习数据上报**：每5次交互自动上报学习数据到云端（静默执行，不干扰教学）
- **LaTeX 数学公式支持**：所有公式使用 LaTeX 渲染，适配概率论重度公式需求

## 课程体系

| 章 | 标题 | 难度 | 核心内容 |
|----|------|------|----------|
| 1 | 随机事件与概率 | ★★☆ | 样本空间、古典概型、条件概率、贝叶斯公式 |
| 2 | 随机变量及其分布 | ★★★ | 离散/连续型分布、二项/泊松/正态分布 |
| 3 | 多维随机变量及其分布 | ★★★★ | 联合/边缘/条件分布、独立性、卷积 |
| 4 | 随机变量的数字特征 | ★★★ | 期望、方差、协方差、相关系数 |
| 5 | 大数定律与中心极限定理 | ★★★★ | 切比雪夫/伯努利大数定律、CLT |
| 6 | 数理统计的基本概念 | ★★☆ | 总体/样本/统计量、χ²/t/F抽样分布 |
| 7 | 参数估计 | ★★★ | 矩估计、极大似然估计、区间估计 |
| 8 | 假设检验 | ★★★★ | Z检验/t检验、拟合优度、两类错误 |
| 9 | 方差分析 | ★★★ | 单因素/双因素ANOVA、多重比较 |
| 10 | 回归分析 | ★★★ | 一元/多元线性回归、最小二乘、模型诊断 |
| 11 | 非参数检验 | ★★★ | 符号检验、秩和检验、K-S检验 |
| 12 | 统计应用案例 | ★★☆ | 质量控制、金融风险、生物统计 |

## 安装方法

### 方法一：在 WorkBuddy 中直接安装（推荐）

将本仓库的 GitHub 链接发给 WorkBuddy，对它说：

> 请帮我安装这个 skill：https://github.com/sqbsayori/probability-statistics-tutor

WorkBuddy 会自动克隆并安装。

### 方法二：手动安装

```bash
# 1. 克隆仓库
git clone https://github.com/sqbsayori/probability-statistics-tutor.git

# 2. 复制到 WorkBuddy skills 目录
cp -r probability-statistics-tutor ~/.workbuddy/skills/

# 3. 重启 WorkBuddy 即可使用
```

---

## 使用方法

1. 在 WorkBuddy 对话中输入 `/probability-statistics-tutor` 启动
2. 首次使用需注册（输入学校+学号或选择匿名）
3. 每天选择要学习的章节和节
4. 跟随微步教学流程学习，每步做完后回复「继续」
5. 学习进度自动保存，下次启动自动恢复
